## 🧠 Dynamic Memory Allocation

I practice dynamic memory management in C, including:

* `malloc()` — Allocates a block of memory.
* `calloc()` — Allocates memory for multiple elements and initializes it to zero.
* `realloc()` — Changes the size of an allocated memory block.
* `free()` — Releases dynamically allocated memory.

These concepts help me understand memory usage and pointer-based programming.

## ▶️ How to Run a C Program

You can run the programs on your computer using GCC.

### Step 1: Install GCC

Install a suitable GCC compiler for your operating system and make sure it is available in your terminal's `PATH`.

### Step 2: Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/kumarabhiraj05981-dot/c-language-practice.git
```

### Step 3: Open the Project Folder

```bash
cd c-language-practice
```

### Step 4: Compile a C Program

For example, to compile a file named `01_Snake_Water_Gun.c`:

```bash
gcc "Project 2/01_Snake_Water_Gun.c" -o snake_water_gun
```

### Step 5: Run the Program

On Windows PowerShell:

```powershell
.\snake_water_gun.exe
```

On Linux or macOS:

```bash
./snake_water_gun
```

**Note:** The filename and folder must match the actual program you want to run.
